# Jrose WEAPON import, batch 2 -- our IDs 1420-1453, imported 2026-09-06.
#
# Batch 1 took the three sets that cover all 13 weapon types. This takes the two
# that do not (they are still coherent sets, just incomplete), plus the level-210
# tier and a handful of one-off crossbows and staves:
#
#   lv210     6 types    the 210-pattern service tier -- blunt, 2H sword, axe,
#                        gun, launcher, wand. The other seven types have no
#                        lv210 model we do not already own.
#   Tochu     11 types   mesh tochu_*, insect names: Anansi, Selket, Shelob,
#                        Arachne, Psyche, Hepri, Myrmecoleon... (no spear, no dual)
#   Toshin    10 types   mesh toshin_*, giant names: Jotunn, Titan, Gigantes,
#                        Nephilim, Hecatoncheir, Kumbhakarna... (no spear, katar
#                        and dual are covered but 2H sword and staff are not)
#   singles   7 rows     3 crossbows + 4 staves, filling the level bands below
#                        200 where our own ladder is thinnest.
#
# STATS ARE OURS. As in batch 1, every row is anchored to OUR lv230 flagship for
# its own weapon type (rows 1355-1367), so each entry sits on our scale and keeps
# that type's character -- a katar stays fast, an axe stays slow:
#
#   lv210   lv210  ATK x0.85  speed = type baseline       no bonus
#   Tochu   lv220  ATK x0.98  speed = type baseline       +20 AVOID
#   Toshin  lv235  ATK x1.06  speed = baseline + 1 (slow) +120 HP
#   singles varies                                        varied
#
# Bonus ids are deliberately different from batch 1 (which used AT_HIT 20 and
# AT_CRITICAL 26) so the sets stay distinguishable in play: AT_HP is 16, AT_MP 17,
# AT_AVOID 22. Attack speed is inverted -- LOWER is faster (1500/(value+5)).
#
# THE REQUIREMENT GATE IS DERIVED FROM THE ITEM'S OWN LEVEL, not from a per-set
# constant: reqmul = 0.50 + 0.50 * (level - 140) / 100, applied to the template's
# requirement value. A flat per-set multiplier is what decoupled six imported
# shields from their levels (see scripts/fix-shield-str-gates.py); the first draft
# of this batch reproduced it exactly, handing four staves spanning levels 150-205
# the same INT 288 gate. The requirement ABILITY is whatever that weapon type
# already requires, read off the template -- STR for swords, DEX for bows and
# katars, CON for guns, INT for casters -- never assumed.
#
# THE TEMPLATE MUST BE THE SAME WEAPON TYPE. --art-only clones every other column
# from it, including type, range and the requirement ability id.
#
# THE ATK VALUES ARE ANCHORED TO THE FLAGSHIP'S *EFFECTIVE* ATK, and they were
# corrected after the first import. A row has only two bonus slots (game cols
# 24/25 and 27/28), and slot 1 is where all 13 flagships keep an ATK bonus --
# ATK+10 on most types, +30 on staff/wand/katar, **+90 on dual**. `--bonus`
# fills slot 1 first, so passing one silently overwrote it: 52 of the 73
# imported rows lost that ATK, and five ended up weaker than the level-230
# weapon they were scaled *up* from (Giranda, the level-240 mythic dual, sat 34
# ATK under Dual Viper Blades). The lost ATK is now folded into the ATK column,
# which is equivalent for combat -- both feed the same ATK term -- and the
# values below are post-correction, so a replay reproduces them directly.
# See scripts/fix-weapon-atk-bonus-loss.py for the derivation.
#
# ANYTHING NOT OVERRIDDEN IS STILL THE TEMPLATE'S. 42 rows carry a second bonus
# inherited from their flagship -- INT+60/+50 on staves and wands, CRIT+75 on
# katars, AVOID+80 on bows, DEX+10 on duals. That is deliberate: it is what
# keeps a caster weapon feeling like one. Where the set bonus names the same
# ability the two stack (Spriggan CRIT 18+75, Selket AVOID 20+80), which is
# also intended -- the set bonus is meant to sit *on top* of the type's normal
# character.
#
# Fields, pipe-separated:
#
#   jrose_row | our_template_row | name | description | ATK | atk_speed | req_level | req_stat(id:val) | bonus(id:val, may be empty)
#
# Replay (from the repo root; --dry-run first):
#
#   grep -v '^#' doc/jrose-weapon-batch2.txt | while IFS='|' read -r row tmpl name desc atk spd lv req bonus; do
#     b=""; [ -n "$bonus" ] && b="--bonus $bonus"
#     python scripts/import-item.py --type weapon \
#       --source "C:/Users/Thomas/Desktop/Testclients/Jrose" \
#       --source-row "$row" --art-only --template-row "$tmpl" \
#       --name "$name" --desc "$desc" --atk "$atk" --atk-speed "$spd" \
#       --req-level "$lv" --req-stat "$req" $b --copy-icon
#   done
#

# Jrose WEAPON import, batch 1 -- our IDs 1381-1419, imported 2026-09-06.
#
# Three complete cross-class sets, 13 weapon types each. Jrose has 555 new weapon
# models but roughly half are novelty (a pizza-paddle staff, an ukulele wand, a
# takoyaki-plate crossbow). Underneath that are five sets designed together, one
# model per weapon type; these are the three that cover all 13:
#
#   Mirere    mesh 215_*        the level-215 tier set
#   Rose      mesh rose_*       named for rose cultivars: Rosengarten, La Bella,
#                               Amorosa, Ducat, Elfe, Angela, Georgette, Escada...
#   t_unique  mesh t_unique_*   mythic names: Bahamut, Phoenix, Griffon, Unicorn,
#                               Mermaid, Spriggan, Quetzalcoatl, Catoblepas...
#
# (The other two, tochu/insect and toshin/giant, cover 11 and 10 types and are
# still available -- see doc/jrose-back-import.md's sibling notes.)
#
# STATS ARE OURS, AND THE THREE SETS ARE DELIBERATELY NOT THE SAME. Each is
# anchored to OUR lv230 flagship for that weapon type, so every entry sits on our
# scale and keeps the type's character -- a katar stays fast, an axe stays slow:
#
#   Mirere    lv215  ATK x0.90  speed = type baseline       no bonus
#   Rose      lv225  ATK x0.96  speed = baseline - 1 (fast) +25 HIT
#   t_unique  lv240  ATK x1.12  speed = baseline + 1 (slow) +18 CRITICAL
#
# Attack speed is inverted in the data: LOWER is faster (attack_speed =
# 1500/(value+5)). HIT is AT_HIT=20 and CRITICAL is AT_CRITICAL=26; both are flat
# values, and CRITICAL is a real damage term in type-0 skill damage.
#
# The requirement stat uses whatever ability that weapon type already requires,
# read off the template rather than assumed -- STR for swords, DEX for bows and
# katars, CON for guns, INT for casters -- scaled x0.88 / x0.94 / x1.05 by tier.
#
# THE TEMPLATE MUST BE THE SAME WEAPON TYPE. --art-only clones every other column
# from it, including type, range and the requirement ability id, so templating a
# bow on a sword would produce a bow with sword range and a STR gate. Each row
# below templates on our own flagship of its own type (rows 1355-1367), and the
# verification checks that every imported row kept its type.
#
# Fields, pipe-separated:
#
#   jrose_row | our_template_row | name | description | ATK | atk_speed | req_level | req_stat(id:val) | bonus(id:val, may be empty)
#
# Replay (from the repo root; --dry-run first):
#
#   grep -v '^#' doc/jrose-weapon-batch1.txt | while IFS='|' read -r row tmpl name desc atk spd lv req bonus; do
#     b=""; [ -n "$bonus" ] && b="--bonus $bonus"
#     python scripts/import-item.py --type weapon #       --source "C:/Users/Thomas/Desktop/Testclients/Jrose" #       --source-row "$row" --art-only --template-row "$tmpl" #       --name "$name" --desc "$desc" --atk "$atk" --atk-speed "$spd" #       --req-level "$lv" --req-stat "$req" $b --copy-icon
#   done
#
